# Core Concepts

## Framing
- **Focus:** what the project is about.
- **Goal:** what the project seeks to achieve or understand.
- **Project role:** contextual relation such as target, reference, off_target, substrate, scaffold, analyte, partner. Target is a role, not an intrinsic universal type.

## Reasoning
- **Question:** scientific uncertainty.
- **Hypothesis:** testable proposition.
- **Strategy:** scientific approach to pursue a Goal or investigate a Question/Hypothesis.
- **Claim (provisional):** explicit scientific assertion supportable/challengeable by evidence. Kept provisional until concrete schemas demonstrate that it adds value beyond Result/Observation/Hypothesis.

## Execution
- **Campaign:** project-specific coordinated activity.
- **Experiment:** empirical investigation.
- **Run:** concrete execution instance.

## Outputs and interpretation
- **Artifact:** concrete input/output.
- **Result:** processed/computed outcome.
- **Observation:** scientifically meaningful noticed pattern/phenomenon; may generate Questions/Hypotheses.
- **Evidence:** information supporting, contradicting, or informing a Question/Hypothesis/Claim.

`Artifact ≠ Result ≠ Observation ≠ Evidence`.

## Candidates
- **Candidate:** optional project-specific role of an entity, variant, design, construct, assembly or proposed solution; type-agnostic.
- **Candidate collection:** need accepted; exact name/schema open.

## Knowledge references
Nextia may reference Sabueso Cards/evidence or external literature/databases without copying them into project-generated Evidence.

## Identity
Graph objects require stable identities/references. Prefer:
`Hypothesis H3 → Evidence E17 → Result R9 → Artifact A21`
over recursive embedding.

## Governance
- **Decision:** explicit project choice.
- **Provenance:** trace of origins/transformations.
- **Supersession:** later interpretations/decisions may supersede earlier ones without deleting history.
