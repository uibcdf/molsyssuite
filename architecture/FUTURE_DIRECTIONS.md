# MolSysSuite — Future Directions

The architecture should absorb new scientific domains without changing its four-column structure.

## Potential Modeling domains
- free-energy calculations;
- quantum chemistry;
- property prediction / ADMET;
- QSAR;
- generative chemistry;
- retrosynthesis;
- protein/peptide design;
- advanced conformational sampling;
- molecular/material design domains beyond pharmacology.

## Praxis evolution
- public/private Capability registries;
- Capability maturity levels;
- benchmark/validation suites;
- protocol selection based on accuracy, cost, data and uncertainty;
- reusable organization-specific scientific know-how.

## Nextia evolution
- project templates;
- richer uncertainty/evidence graphs;
- experimental-data ingestion;
- multi-objective discovery;
- portfolio/program-level structures above DiscoveryProject if real use eventually requires them.

## MolSys-AI / MOLI evolution
- richer scientific planning;
- uncertainty-aware proposals;
- capability composition;
- automated but reviewable protocol drafting;
- organization-specific knowledge and method access.

## Experimental/physical loop
Long-term, the architecture can close a computation→experiment→evidence loop, including laboratory automation, without making laboratory automation part of Nextia's core domain.
