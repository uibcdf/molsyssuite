# Native interface characterization coordination

## What

Review TopoMT's published native catalogue and BindingMT's selected interface
design/implementation sections. The [central review](../native_interface_characterization.md)
records ownership, contacts/SASA/burial definitions, effective populations,
source/local correspondence, quantity/attribution boundaries, independent
controls and the exact decisions still needed by each owner.

## How and why

Immutable owner documents and actual MolSysMT public source are inspected and
hashed in the [batch receipt](../rollouts/third_ten_receiving_20261112.json).
The contact cutoff includes equality; `pairs=True` and pair output have different
meanings. SASA output selection preserves other input occluders. Rose reference
buried-area tables are not geometric interface burial. These concrete differences
need explicit receiving rather than another molecular kernel or a parallel schema.

## Acceptance

- Record finite agreed definitions and actual required/optional facts per selected operation.
- Receive BindingMT's local milestone/default/result decisions, MolSysMT's selected
  public-call/context/map/radius disposition and TopoMT's enrichment disposition.
- Identify concrete owner gaps only after reviewing the actual selected operation.
- Retain implementation, independent controls, installed/public/native evidence
  and each consumer's adoption state separately.
