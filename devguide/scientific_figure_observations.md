# Optional scientific context retained with figures

Boundary review under #179 accepts an experimental optional source contract,
without mandating a shared scientific schema or changing public dependency floors.
MolSysViewer owns generic visualization/persistence; MolSysMT owns the initial
scientific producer. MolI project Evidence/Provenance remains a separate contract.

The reviewed Viewer contract at `5164f13bb503625dbe65f3b657ab5260feadcb65`
accepts optional detached opaque JSON observations per displayed series. Existing
numeric/title/axis calls and states remain valid. Unknown producer schemas are
preserved/displayed literally; no evaluation, HTML, implicit recalculation or
generic molecular interpretation is introduced. Bounded decoding rejects invalid,
nonfinite/cyclic/oversized records before attachment, without truncation.

The original row count/context and composed row maps preserve repeated or
nonconsecutive extracted selections. Clearing a mounted producer report preserves
an adopted figure; explicitly clearing the figure removes it. Copy, scene/state/
session recovery, canvas/DataCard popup and detached Studio retain their distinct
owner-tested boundaries. History is separate from present applicability; declared
IDs/maps/revisions neither authenticate molecular origins nor observe raw edits.

MolSysMT's experimental `molsysmt.figure_observation@1` at contribution
`9dff314f896238d8d9968c3c86b9b901adf6e81a` owns method/default/parameters,
ordered populations/reference, weights/mass source, native/display units,
coverage/projection and observed software versions. Exact arithmetic-run axes and
hexadecimal plain binary64 encodings preserve selection/value identity; physical
quantities use the existing PyUnitWizard QuantityRecord with explicit reader
field/unit expectations. No second quantity codec or shortened population is
accepted. Preserve original molecular/reference bytes and environment for actual
reproduction; metadata and digests alone cannot recreate missing inputs.

Owner source receipts report real producer-data, Clear/edit/reference/extraction,
literal-rendering and recovery/popup controls, with browser, Jupyter and Qt scopes
separate. Central review verifies immutable contracts/receipt identities; it does
not rerun those scientific/GUI results or certify a covering installed/public pair.
MolSysViewer #349 and MolSysMT PR #702/#696 retain source delivery; #315/#421 and
owning release/installed/human gates retain broader acceptance. Other addons may
opt in after their own review and need no migration now.
