# Decisions and Remaining Questions

## Accepted
- Four columns remain stable.
- MolSys-AI/MOLI is transversal and optional.
- Nextia is AI-independent.
- Focus + Goal replace generic Objective.
- Target is contextual role.
- Observation is core.
- Nextia is graph-shaped.
- Candidate optional/type-agnostic.
- Strategy ≠ Protocol; Campaign ≠ Protocol.
- Artifact ≠ Result ≠ Observation ≠ Evidence.
- External knowledge ≠ project Evidence.
- Stable identity/reference principle.
- Failures/conflicts/inconclusive/rejected/superseded states are first-class.
- Scientifically meaningful history is auditable.

## Provisional
- Claim object.

## Open
- project entity/system schema;
- candidate collection naming/schema;
- graph relation vocabulary;
- project fork/lineage model;
- storage/backend;
- Capability composition semantics;
- exact maturity/validation states;
- external knowledge snapshot/version mechanism;
- cross-project sharing;
- Engine event model.

## Freeze criterion
Architecture 1.0 can be frozen when concrete schemas/examples for Praxis and Nextia demonstrate that no additional top-level domain concept is required and the provisional Claim question is resolved.
