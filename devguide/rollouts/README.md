# Suite-wide rollouts

Rollouts apply an accepted policy or contract across member repositories. They are not
proposals: the decision is already normative. Their documents hold the changing adoption
matrix and link local implementation issues; the central issue holds public state and the
final outcome.

- [`policy_v1.md`](policy_v1.md) — `uibcdf/molsyssuite#6` — adoption of the Python,
